## Use OpenKermit for the daily use

Unless you have the reasons to run kermit in a resource-limited
environment, using OpenKermit will suffice in most modern computers.

See <https://www.openkermit.org/> for the OpenKermit Project.

## Modifications in this repository

Code is tested under the following systems:

* macOS
* Ubuntu (26.04)
* Raspberry Pi OS
